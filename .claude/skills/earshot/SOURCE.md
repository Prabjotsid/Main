# Where this skill comes from

`SKILL.md` is copied unchanged from the open-source project
[Leonxlnx/earshot](https://github.com/Leonxlnx/earshot) (MIT licence, see `LICENSE`),
at commit `4ac3d2a` (version 0.4.1).

The skill needs the `earshot` command. Install it with:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install "git+https://github.com/Leonxlnx/earshot@4ac3d2a"
```

The first call that listens downloads two audio models (about 1.1 GB) from Hugging Face.
